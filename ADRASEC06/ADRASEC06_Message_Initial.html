Aide a la redaction

Le formulaire s'adapte au type de message choisi en haut de page.

Message d'ambiance

Premier compte rendu depuis le terrain, transmis des l'arrivee sur les lieux. Il donne une premiere image de la situation.

Message de situation

Compte rendu periodique qui actualise l'ambiance : evolution, moyens, besoins.

Message encapsule

Transport d'un message redige par une autorite. Le radioamateur n'en est pas l'auteur : il indique l'autorite d'origine et l'autorite destinataire, puis recopie le texte sans le modifier.

Les quatre rubriques

  • Je suis : ou je me trouve, avec quels moyens.
  • Je vois : ce que j'observe, sans interpretation.
  • Je fais : les actions que j'ai engagees.
  • Je demande : les moyens ou instructions dont j'ai besoin.
Les accents sur les majuscules sont supprimes automatiquement a l'envoi (contrainte de transmission Winlink).

Champs

  • N° du message : pre-rempli par Winlink, modifiable.
  • Date / Heure : bouton UTC / LOC pour basculer de fuseau.
  • Origine : indicatif de la station emettrice (fond jaune).
  • Destinataire(s) : indicatifs separes par des points-virgules.
  • Autorites (fond vert) : uniquement pour un message encapsule.
